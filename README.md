# 創立者列伝 — FOUNDERS CLASH (v2 / Street Fighter Edition)

大学創立者20人による、ビルド不要の2Dブラウザ格闘ゲーム。写真・肖像画を参照したイラストと、名言・座右銘・書を題名にした必殺技を収録。
v2 では戦闘システムと演出をスト2風に全面改修し、各キャラクターのポーズを3種から9種に増やした。

**▶ 遊ぶ: https://piro2020.github.io/founders-clash/**

> 本作は非公式のファン創作です。各大学・学校法人・ご遺族とは一切関係がなく、公式作品ではありません。
> キャラクターイラストは AI 生成で、人物描写・能力・戦闘はすべてフィクションです。詳細は末尾の「免責・権利について」を参照。

- CPU対戦（3段階）、同じキーボードでの2人対戦、5人抜き
- 立ち/しゃがみ弱強、足払い、ジャンプキック、投げ（密着で前＋強）
- 後ろ入力ガード（しゃがみガードは下段、立ちガードは中段/ジャンプ攻撃に対応）
- 必殺技（Lボタン、または ↓↘→＋攻撃のコマンド入力でダメージ+15%）、信念ゲージ100で超必殺（Iボタン）
- 弱→強→必殺のキャンセル、コンボ表示、ダウン、KOスローモーション、PERFECT、勝利ポーズ
- VS画面、超必殺の暗転カットイン、名言読み上げ、英語アナウンス、ステージ別BGM（すべてWeb Audio/音声合成、音声ファイルなし）
- 4ステージ、タッチ操作、一時停止、放置時のCPU同士デモ
- 大学公式資料に基づく人物図鑑（共同創立者・前身校を含む）

## ローカル起動

`npm run dev` を実行し、http://127.0.0.1:4173 を開く。依存パッケージのインストールは不要。Node.jsはテスト用、配信にはPython 3を使用。

## 操作

| | 1P | 2P |
|---|---|---|
| 移動 | A / D | ← / → |
| ジャンプ | W | ↑ |
| しゃがみ | S | ↓ |
| 弱 / 強 / 必殺 / 超必殺 | J / K / L / I | 1 / 2 / 3 / 4 |

ガードは相手と逆方向に入力（後ろ入力）。スマホは画面下のボタン（盾ボタンで明示ガード）。

## 検証

`npm test` で戦闘ロジックの33テストを実行。必殺技、当たり判定、後ろ入力ガード、下段/中段の判定、投げ、236コマンド、超必殺、ダウン無敵、スローモーション、キャンセル、CPU同士のラウンド時間などを検証。

## ファイル

- `dist/founders.js`: 人物、公式出典、ゲーム内の性能
- `dist/quotes.js`, `dist/portrait-sources.js`: 名言の帰属・文脈と肖像の参照元
- `dist/engine.js`: 描画に依存しない戦闘ロジック（入力・判定・CPU・ラウンド進行）
- `dist/illustrated-art.js`: スプライト、ステージ、HUD、VS画面、カットイン、演出の描画
- `dist/assets/`: WebP化した透過スプライトアトラス（A: 構え/パンチ/キック、B: しゃがみ/被弾/ジャンプキック、C: 必殺/勝利/ダウン）、4ステージ、キービジュアル
- `dist/sprite-frames.js`: 各人物・ポーズの描画範囲（A/B/C アトラス）
- `scripts/analyze-sprites.py`: 画像を変更せず、透過部分を解析して描画範囲を記録
- `dist/app.js`: UI、操作、モード進行、音、アナウンス
- `dist/index.html`, `dist/style.css`, `dist/arcade.css`: 画面構成とレスポンシブ表示
- `.github/workflows/pages.yml`: push 時にテストを実行し、`dist/` を GitHub Pages へデプロイ

## 制作メモ（v2）

- 追加ポーズとキービジュアル・ステージ04は、既存アトラスを参照画像として画像生成で制作した。生成画像の市松模様の疑似透過は、規則格子を検出して透過化した。
- 元のPNGアセットはGit履歴に残している。配信サイズは約40MBから約5MBに削減。

大学名は2026年10月時点。創立年は前身校・母体学園を含む。名言と肖像の参照元はゲーム内の人物図鑑から確認できる。
